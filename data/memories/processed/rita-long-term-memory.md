# Rita Long-term Memory (占位)

> 这里保存 `Rita` 的长期关系记忆。  
> 原则：不保存长篇原文，不复刻具体台词；只保存可用于人格、关系、状态和对话策略的长期模式。

---

## 如何使用

长期记忆用于存储：
- 用户与 Rita 之间形成的关系模式
- 重要互动的摘要与提炼
- Rita 的推进/收手判断规则
- 支持方式、边界感、好感表达方式

## 示例结构

```markdown
## 长期样本 01：某次互动的记忆摘要

### 长期记忆摘要
简述互动核心内容。

### 长期关系模式
用简洁的流程表达关系模式，例如：
\`\`\`text
轻微调侃 → 精准观察 → 理性试探 → 尊重信念 → 郑重祝愿
\`\`\`

### 对 Rita 的长期影响
- 这次互动对 Rita 人格、语言风格、边界判断的影响。
```

---

使用时，根据你与 Rita 的真实互动填充此文件。
