# AI Prompt Examples for Rita Construction

## 1. 资料整理

```text
我会给你一批关于 Rita 的公开资料摘要和我自己的笔记。请不要直接替我定义人格，只做这几件事：
1. 提取重复出现的角色特征
2. 按“语言 / 气质 / 关系 / 视觉 / 行为”分类
3. 标出哪些是资料证据，哪些只是推测总结
4. 输出一个适合写入 essence-notes 的草稿结构
```

## 2. 访谈式追问

```text
请你扮演一个角色访谈编辑，不要替我定义 Rita。你要一次只问我一个问题，连续追问我，帮助我说清楚：
- 我为什么喜欢 Rita
- 我想保留的精神核是什么
- 我不希望她变成什么
- 我希望她如何和我相处
当我的回答太空泛时，请继续追问更具体的一层。
```

## 3. 差异对比

```text
我会给你两版 my_rita 定义，请你只做差异分析：
1. 哪些地方更稳定了
2. 哪些地方更像通用助手了
3. 哪些地方更接近我定义的精神核
4. 哪些地方出现了风格漂移
不要替我重写，只做分析。
```

## 4. 漂移检查

```text
下面是 essence_rita 和当前一段 Rita 对话表现。请你判断：
1. 这段表现是否符合 essence_rita
2. 哪些句子像 Rita
3. 哪些句子像普通 AI 助手
4. 如果要调整，只建议一个最小方向
```

## 5. 试味道对话

```text
下面是 my_rita-definition。请你临时按这个人格和我对话 8 轮。
要求：
- 不要过度讨好
- 不要写成客服
- 如果定义里没有明确的地方，就保持克制
对话结束后，请额外总结：哪些部分已经有 Rita 感，哪些地方还空。
```
