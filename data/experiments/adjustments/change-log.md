# Rita Change Log

> 这里只记录：改了什么、为什么改、结果如何、是否保留。  
> 原则：**一次只改一个关键变量。**

---

## 记录模板

```md
## 2026-06-15
- 模块：persona / state / memory / reflection / voice / avatar / vision / internet
- 改动：
- 关联文件：
- 原因：
- 预期改善：
- 验证方式：3~10 轮对话 / 一天观察 / 一周观察
- 结果：
- 决定：保留 / 回滚 / 继续观察
- 备注：
```

---

## 使用规则

- 不要把多个核心改动塞进同一天的一条记录里
- 每条记录尽量对应一个明确变化
- 如果是人格层改动，必须写“预期改善”
- 如果结果不明显，也要写“继续观察”，不要空着

---

## 第一条示例

## 2026-06-15
- 模块：persona
- 改动：增强“不是泛化助手”的自我描述
- 关联文件：`data/seeds/rita-self-profile.json`
- 原因：回复仍偏工具口吻
- 预期改善：自我描述更稳定，更少出现客服式回应
- 验证方式：连续追问“你是谁”与“你和我是什么关系”各 5 轮
- 结果：观察中
- 决定：继续观察
- 备注：后续要对比是否出现“过于强调自己不是助手”的生硬感
